🔒 Envelope Encryption v3 & Multi-Device Sync

PixieVault utilizes envelope encryption. A random 256-bit Vault Master Key (VMK) encrypts all application data and sealed workspaces. The VMK is wrapped independently by:

  • Universal Argon2id Passphrase Protector: Allows recovery and multi-device OneDrive synchronization.
  • Device-Bound Windows Hello / TPM Protectors: Non-exportable hardware-backed keys on each enrolled PC.

📦 Air-Gapped Portable Packages (.pvpkg)

Portable .pvpkg files bundle the application's source code, manifest, icons, requirements, and optionally encrypted user databases into an offline zip bundle. Use Storage & Data → Export Portable Package or Apps → Import .pvpkg.

Verify Ed25519 Package Signatures

PixieVault verifies all .pvpkg bundles against developer public keys using Ed25519 cryptographic signatures before runtime mounting.
