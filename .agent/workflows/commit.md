# Smart Commit Workflow

Use this workflow to analyze your changes and create a professional git commit.

## 1. Analyze Changes
- Review staged and unstaged changes.
- Identify the scope and type of changes (feat, fix, refactor, etc.).

## 2. Target Files
- If a description was provided (e.g. "commits only the tests"), stage only the relevant files.
- Otherwise, stage all meaningful changes.

## 3. Generate Message
Create a **Conventional Commit** message:
- **Type**: feat, fix, docs, style, refactor, test, chore
- **Scope**: optional component name in parentheses
- **Subject**: imperative, present-tense description

## 4. Commit
Execute the commit. Do **not** include "Claude" or "AI-generated" in the message.
