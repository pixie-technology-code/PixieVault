# Strategic Research Workflow

Use this workflow to gather intelligence before implementing unfamiliar technologies.

## 1. Define objectives
- What specific library, API, or pattern needs research?
- Identify versions from the project's configuration (e.g. `package.json`).

## 2. Structured Search
- Find **Official Documentation** for the specific versions in use.
- Look for **Gotchas** and common implementation pitfalls.
- Search for **Best Practices** regarding security, performance, and accessibility.

## 3. Synthesis
Organize findings for the implementation plan:
- **Direct Links**: specific section anchors.
- **Key Insights**: what affects the implementation.
- **Mitigation Strategies**: how to avoid the identified gotchas.

## 4. Integration
Cross-reference findings with existing codebase patterns to ensure compatibility.
